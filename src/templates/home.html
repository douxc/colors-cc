🎨 colors-cc API

Free, stateless color & placeholder API built for developers and AI agents

Explore APIs ↓ Try Interactive Tools →

Built on the edge with Cloudflare Workers. Generate random colors, curated palettes, and dynamic SVG placeholders instantly.

1. Animated Fluid Gradient Placeholder API

Generate animated SVG placeholders with smooth color transitions and dynamic gradient effects. Perfect for hero banners and modern UI designs.

GET https://api.colors-cc.top/fluid-placeholder

Query Parameters:
  • w: Image width in pixels (default: 800, range: 50-4000)
  • h: Image height in pixels (default: 400, range: 50-4000)
  • stops: Comma-separated HEX colors (2-10 colors, e.g. %23FFD6A5,%23FFADAD,%23E2A0FF)
  • speed: Animation duration in seconds (default: 10, range: 1-30)
  • text: Optional center text (max 100 chars)
Try Endpoint → Interactive Generator →

2. SVG Image Placeholder API

Generate dynamic, lightweight, and customizable SVG gradient placeholder images for your projects.

GET https://api.colors-cc.top/placeholder

Query Parameters:
  • w / width: Image width in pixels (default: 800)
  • h / height: Image height in pixels (default: 400)
  • text: Center text content (default: width x height)
  • start: Gradient start hex color (e.g. %23F06292)
  • end: Gradient end hex color (e.g. %2364B5F6)
Try Endpoint →

3. Color Palette API

Fetch a curated color palette by theme for UI design inspiration.

GET https://api.colors-cc.top/palette

Available Themes:
Cyberpunk
Vaporwave
Retro
Monochrome
Query Parameters:
  • theme: Theme name. Options: cyberpunk, vaporwave, retro, monochrome (default: cyberpunk)
Try Endpoint →

4. Random Color API

Generate a completely random color in HEX and RGB formats. Perfect for frontend mock data and placeholders.

GET https://api.colors-cc.top/random

#FF5733
rgb(255, 87, 51)
Response format:
  • hex: The color in HEX format (e.g. #FF5733)
  • rgb: The color in RGB format
  • timestamp: Generation time
