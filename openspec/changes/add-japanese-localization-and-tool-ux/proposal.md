# Proposal

## Why

目前网站仅提供英文和简体中文，日文访客需要自行理解操作说明；工具还存在语言切换丢失输入、复制失败仍显示成功、请求完成顺序影响结果等使用障碍。已观察到少量日本访问，但样本不足以判断需求规模；本次依据用户明确要求提供完整日文，并降低首次访问者完成任务的难度。

## What Changes

- 全球站增加 `/ja` 首页及全部 16 个工具页面，包括通用转换器、12 个定向转换页面、配色、CSS 颜色名称和流动占位图；翻译页面文案、动态反馈、辅助技术标签、生成结果中的说明和搜索元信息。
- 提供日文文档 `/ja/llms.txt`、`/ja/skills/colors-cc.md`、`/ja/openapi.json`，日文页面链接到对应文档；保持 API 参数、CSS 标准名称、代码标识符和既有文档地址兼容。
- 以“选择任务 → 查看默认结果 → 调整必要参数 → 复制结果”为主要流程；主页提供明确工具入口，技术代码和高级选项按需展开。
- 语言菜单明确显示 English、简体中文、日本語，切换后保留当前页面、输入、搜索条件和页面位置；日文页面适配小屏幕及键盘操作。
- 为各工具补充就近输入提示、可执行的错误恢复、可靠复制反馈、请求顺序保护；转换页面强调来源和目标，配色支持整组复制，颜色名称支持清除搜索和重试。
- 增加日文 canonical、hreflang、结构化数据及 XML/TXT sitemap；覆盖多语言页面、操作状态和两种部署的回归验证。

## Capabilities

### New Capabilities

- `japanese-localization`: 全球站日文页面和文档的完整覆盖、多语言入口、日文元信息与部署兼容性。
- `visitor-tool-workflows`: 面向访客的工具入口、参数调整与复制流程，以及跨语言状态保留、错误恢复和无障碍操作。

### Modified Capabilities

无。项目目前没有已登记的主规范。

## Impact

- 主要涉及 `src/site.ts`、`src/app.tsx`、`src/i18n/`、共享导航/布局/样式、首页模板、工具页面、文档路由、SEO 与 sitemap，以及已有测试和 SEO 检查脚本。
- 全球站英文和中文路径继续可用；中国站保持仅简体中文，不增加日文页面。既有无语言前缀地址与根文档继续兼容。
- 使用现有 Hono、TypeScript 和外部 colors-cc API；不修改独立 API 服务，不新增账号、服务端存储或翻译服务依赖。
- 范围包含本仓库对访客公开的页面和文档；不包含独立 offline-tools 应用、第三方网站、许可证原文或开发者仓库文档的翻译。
